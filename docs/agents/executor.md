# Executor Node

The **Executor** is the hands-on component of Autonoma. It translates the theoretical plans of the agents into actual data operations by calling tools on the MCP server.

## 🎯 Role
- Parse the JSON tool calls generated by agents.
- Interface with the `mcp_session`.
- Execute tools sequentially.
- Capture results (observations) and update the state.
- Handle tool failures and errors gracefully.

## 🛠️ Execution Flow
1. **Parsing**: It extracts the list of tool calls from the agent's response (handling Markdown blocks if present).
2. **Looping**: For each call, it identifies the `tool_name` and `params`.
3. **MCP Call**: It uses `await session.call_tool(...)` to trigger the Python function on the server.
4. **Observation**: The result of each tool is collected into a formatted string.
5. **State Mapping**: Depending on which agent is active, the results are saved to different state fields:
    - **Analysis**: Updates `eda_insights`.
    - **Preprocessing**: Updates `preprocessing_steps`.
    - **Modeling**: Updates `model_path`, `modeling_results`, `model_params`, and `evaluation_metrics`.

## ⚠️ Error Handling & Propagation
If a tool execution fails or the agent's output is not valid JSON, the Executor:
- Logs the error to the debug console.
- **Propagates the Error**: The error message is returned as the "insight" or "result" for that phase. 
- **Context Preservation**: The error is injected into the subsequent agent's prompt, explicitly labeling it as an execution failure to ensure the next agent is aware of the specific tool that failed and why.

### Behavior per Agent:
- **Error Triggering**: If a tool fails (contains "Error" or "failed") or a Python exception occurs, the Executor increments `critic_iterations` and sets `final_decision` to `"revise"`.
- **Automatic Retry**: The workflow router (`route_after_execution`) detects this `"revise"` decision and loops back to the *current* agent instead of proceeding to the next phase. This allows the agent to observe the error and attempt a fix (consuming one of its allotted iterations).
- **Modeling**: Modeling already has a built-in iteration loop for performance optimization, but execution errors within this phase also trigger a "revise" turn to allow for remediation.

## 📝 Implementation
The node is implemented in `src/autonoma/agents/executor_node.py`. It is an asynchronous function to handle the non-blocking MCP communication.
